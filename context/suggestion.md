This document serves as a suggestion for the App development

1. Dalam pengembangannya mungkin dapat menggunakan live documentation yang terintegrasi pada setiap Pull Request atau mungkin memakai note taker saat meeting dan menggabungkannya menjadi dokumentasi yang terintegrasi dengan sistem pengembangan.
2. Standarisasi Open Agent Control dalam pengembangan agar konsisten antar developer.
3. Penulis seharusnya memanfaatkan Open Agent Orchestration (OAC) agar dalam pengembangan fiturnya selalu konsisten dan promt baru tidak akan menghapus fitur yang sudah ada.
