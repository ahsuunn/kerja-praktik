{\bfseries\Large TERM OF REFERENCE (TOR)\par}
{\bfseries\large PENGEMBANGAN FUNGSI MANAJEMEN PENAGIHAN PIUTANG DAN ALUR REVISI PEMBAYARAN PARAPAY\par}
\vspace{0.3cm}
\textbf{PT PARAGON TECHNOLOGY AND INNOVATION}
\end{center}
\vspace{0.4cm}

\begin{enumerate}[label=\arabic*.,leftmargin=1.0cm]
\item \textbf{TUJUAN PEKERJAAN}\\
  Mengembangkan dan mengoptimalkan fungsi aplikasi Parapay dalam mengelola penagihan piutang usaha (\textit{Account Receivable}), memfasilitasi alur simpan sementara (\textit{Save as Draft}), merefaktor arsitektur alur revisi pembayaran (Revision v2) dengan pemuatan data lama secara otomatis, serta mendukung stabilitas operasional penagihan di seluruh cabang distribusi.

\item \textbf{LINGKUP PEKERJAAN}\\
  \begin{enumerate}[label=\alph*)]
    \item Pengembangan antarmuka dan logika \textit{Save as Draft} pada alur pembuatan koleksi penagihan.
    \item Pembuatan modul Potong Tagihan dengan indikator status dinamik dan pengendalian hak akses (RBAC).
    \item Refactoring arsitektur Revision v1 menjadi Revision v2 yang mendukung pemuatan otomatis data lama, \textit{state invalidation}, mode \textit{read-only}, \textit{non-allocation lock}, dan alur khusus setor tunai.
    \item Integrasi API peramban \textit{IndexedDB} untuk penyimpanan bukti transfer secara luring.
    \item Optimasi antarmuka melalui \textit{server-side search} dan \textit{infinite scroll} pada daftar pelanggan dan area penagihan.
    \item Penyelesaian tiket bantuan operasional dan pemeliharaan basis data produksi pasca \textit{Go Live}.
  \end{enumerate}

\item \textbf{HASIL PEKERJAAN}\\
  Modul aplikasi Parapay yang teruji dan terintegrasi ke repositori utama PT Paragon Technology and Innovation, beserta dokumen laporan Kerja Praktik.

\item \textbf{BATASAN}\\
  \begin{enumerate}[label=\alph*)]
    \item Pengembangan difokuskan pada \textit{frontend framework} berbasis React/TypeScript dan integrasi API \textit{backend}.
    \item Pengujian dilakukan pada lingkungan \textit{staging} dan basis data produksi secara terkontrol bersama pembimbing teknis.
  \end{enumerate}

\item \textbf{LINGKUNGAN PENGEMBANGAN}\\
  \begin{itemize}
    \item \textbf{Perangkat Lunak}: Node.js, React, TypeScript, TanStack Query, Zustand, Git, OpenCode, Zathura.
    \item \textbf{Jaringan}: Paragon Internal Network via VPN.
  \end{itemize}

\item \textbf{METODOLOGI PEKERJAAN}\\
  Menggunakan pendekatan \textit{Agile Software Development} dalam lingkungan \textit{AI-Native SDLC} dengan siklus koordinasi mingguan mencakup \textit{Daily Standup}, pengulasan kode (\textit{Merge Request}), dan pemeliharaan operasional.

\end{enumerate}
