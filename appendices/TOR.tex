{\bfseries\Large TERM OF REFERENCE (TOR)\par}
{\bfseries\large PENGEMBANGAN FUNGSI MANAJEMEN PENAGIHAN PIUTANG DAN ALUR REVISI PEMBAYARAN PARAPAY\par}
\vspace{0.3cm}
\textbf{PT PARAGON TECHNOLOGY AND INNOVATION}
\end{center}
\vspace{0.5cm}

\begin{enumerate}[label=\arabic*.,leftmargin=1.0cm]
\item \textbf{TUJUAN PEKERJAAN}\\
  Mengembangkan dan mengoptimalkan fungsi aplikasi Parapay dalam mengelola penagihan piutang usaha (\textit{Account Receivable}), memfasilitasi alur simpan sementara (\textit{Save as Draft}), serta merefaktor arsitektur alur revisi pembayaran (Revision v2) agar lebih modular, transparan, dan andal bagi petugas FAR di lapangan.

\item \textbf{LINGKUP PEKERJAAN}\\
  \begin{enumerate}[label=\alph*)]
    \item Pengembangan antarmuka dan integrasi logika \textit{Save as Draft} pada alur pemesanan koleksi penagihan.
    \item Pembuatan modul Potong Tagihan, status *badge* dinamik, dan pemisahan detail pembayaran.
    \item Refactoring arsitektur Revision v1 menjadi Revision v2 yang mendukung \textit{state invalidation}, *read-only mode*, dan *non-allocation lock*.
    \item Integrasi API peramban \textit{IndexedDB} untuk penyimpanan bukti transfer pada alur revisi kas.
    \item Optimasi antarmuka melalui *server-side search* dan *infinite scroll* pada daftar pelanggan dan area.
  \end{enumerate}

\item \textbf{HASIL PEKERJAAN}\\
  Modul aplikasi Parapay yang teruji dan terintegrasi ke repositori utama PT Paragon Technology and Innovation, beserta dokumen laporan Kerja Praktik.

\item \textbf{BATASAN}\\
  \begin{enumerate}[label=\alph*)]
    \item Pengembangan difokuskan pada \textit{frontend framework} berbasis React/TypeScript dan integrasi API \textit{backend}.
    \item Pengujian dilakukan terbatas pada lingkungan *staging* dan *development* tim FATL.
  \end{enumerate}

\item \textbf{LINGKUNGAN PENGEMBANGAN}\\
  \begin{itemize}
    \item \textbf{Perangkat Lunak}: Node.js, React, TypeScript, Git, Visual Studio Code / Zed, Zathura.
    \item \textbf{Jaringan}: Paragon Internal Network via VPN.
  \end{itemize}

\item \textbf{METODOLOGI PEKERJAAN}\\
  Menggunakan pendekatan *Agile Software Development* dengan siklus mingguan mencakup *Daily Standup*, pengulasan kode (\textit{Merge Request}), dan pengujian integrasi.

\end{enumerate}
